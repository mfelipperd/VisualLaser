## 2024-06-21 - [Next.js Image `fill` vs `sizes` anti-pattern]
**Learning:** This codebase frequently uses Next.js `<Image>` components with the `fill` property without providing the required `sizes` property. This is a critical performance issue because without `sizes`, Next.js defaults to treating the image as 100vw, forcing the browser to download the largest possible version of the image regardless of the actual container size on the screen.
**Action:** Always verify that `<Image>` components using `fill` also include an appropriate `sizes` property. Use specific pixel values for fixed-size containers (e.g., `sizes="80px"`) and responsive media queries for fluid layouts (e.g., `sizes="(max-width: 768px) 100vw, 50vw"`). Run checks like `grep` to find missing `sizes` before completing PRs related to image optimization.
