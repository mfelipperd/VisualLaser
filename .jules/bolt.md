## 2024-05-24 - [Next.js Image Anti-Pattern: Missing sizes with fill]
**Learning:** Found multiple instances where the Next.js `<Image>` component was used with the `fill` property but without the `sizes` property. This is a common Next.js anti-pattern that forces the browser to download the largest possible image size (often 100vw or even larger if not constrained), leading to significant over-downloading of bytes, increased LCP (Largest Contentful Paint) times, and worse performance, especially on mobile devices.
**Action:** Always include the `sizes` property when using `fill` on a Next.js `<Image>`. The `sizes` property should accurately reflect the responsive width of the image container across different breakpoints to ensure the browser selects the optimal image size from the generated `srcset`.
