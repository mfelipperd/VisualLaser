## 2024-03-20 - [Performance Anti-Pattern: Missing sizes on Next.js Image with fill]
**Learning:** Found Next.js Image components in `components/equipe/DoctorsCatalog.tsx` using `fill` without a `sizes` prop. In a grid of 13 doctors, Next.js will default to serving 13 images at 100vw on all screen sizes, which causes users to download needlessly large images. The `<Image>` components in Next.js when used with `fill` require `sizes` to optimize serving responsive sizes. This severely impacts Largest Contentful Paint (LCP) and bandwidth.
**Action:** Always provide a `sizes` property when using `fill` on the `next/image` component to ensure optimal image delivery across different device sizes. I will optimize the image loading in `components/equipe/DoctorsCatalog.tsx` by defining the `sizes` prop.
